# 尤诺团子桌宠 V5 · 使用说明

## 版本变更（V4 → V5）

| 项目 | V4 | V5 |
|------|----|----|
| 主界面形象 | raise 举牌子人形Q版（白底） | 自绘团子形象（透明底，6种情绪） |
| play/feed/kick | 游戏CG截图（手托光球，非尤诺） | 弃用，改用团子情绪形变动画 |
| 惊讶动画 | peeking（有黑色描边边框） | 团子拉伸 + peeking 多帧偷看 |
| 语气词"呀" | "呀！" | 改为"哇塞！" |
| 语气词长度 | 1-2字短语气词 | 全部加长至5-11秒，增加灵动感 |
| 说明书 | 外部MD文件 | 程序内说明书窗口（右键菜单） |
| 边框问题 | raise白底/peeking黑边 | 全部团子透明底，无边框 |

## 基本操作

- **左键单击** — 跟尤诺聊天（LLM 对话，需配置 API）
- **左键双击** — 摸头（哼~才不是特意让你摸的呢~）
- **左键拖动** — 移动桌宠（喂喂喂！快放我下来啦！）
- **滚轮** — 调整大小（80~500px）
- **右键** — 打开菜单

## 六情绪状态机

| 情绪 | 团子动画 | 触发 |
|------|----------|------|
| 平静 | 呼吸微动 | 默认/超时恢复 |
| 开心 | 弹跳+星星 | 摸头/喂食/LLM回复 |
| 生气 | 抖动+怒气 | 拖拽/LLM回复 |
| 难过 | 缩小+含泪 | LLM回复 |
| 惊讶 | 拉伸+peeking偷看动画 | 戳脸/LLM回复 |
| 傲娇 | 侧转+脸红 | 晚安/LLM回复 |

## LLM 对话配置

首次使用需配置 API：右键 → API 设置

支持 OpenAI 兼容接口（DeepSeek / 通义千问 / 豆包 / OpenAI 等）：
- API Base URL：如 `https://api.deepseek.com/v1`
- API Key：你的密钥
- 模型名称：如 `deepseek-chat`

尤诺会自动回复并输出【情绪】【动作】【特效】标签驱动动画。

## 语音

- **默认**：Edge TTS 在线语音（晓萱少女声线，+10%语速）
- **可切换**：Windows 本地 SAPI（右键 → API 设置 → TTS引擎）
- **长文本跳过**：>80字或含代码/URL时只显示气泡，不播语音
- **5条预录语气词**（AI TTS 风格参考，非真人克隆）：

| 触发 | 语气词 | 时长 |
|------|--------|------|
| 摸头（双击） | 哼~才不是特意让你摸的呢~ | 5.0s |
| 戳脸（右键菜单） | 哇塞！你干嘛戳我脸啦！ | 5.2s |
| 拖拽 | 喂喂喂！快放我下来啦！ | 5.5s |
| 喂食（右键菜单） | 吧唧吧唧~这个好好吃！ | 9.0s |
| 晚安（右键菜单） | 不准松开我……陪在我身边嘛 | 11.2s |

```bash
python v5/src/iuno_pet_v5.py --selftest

```
