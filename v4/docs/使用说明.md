# 尤诺团子桌面宠物 V4 使用说明

## 版本特性

V4 采用 **Bongo Cat 方向**，使用微信官方尤诺表情包（来自库洛游戏官方表情包系列）作为桌宠形象，替换 V3 的 2.5D QPainter 渲染。

### 核心功能

| 功能 | 说明 |
|------|------|
| 表情包动画 | 6 套官方尤诺表情包共 89 帧，按情绪自动切换 |
| 六情绪状态机 | 平静/开心/生气/难过/惊讶/傲娇 |
| LLM 对话 | 接入 OpenAI 兼容 API，跑完整尤诺主提示词 |
| 实时 TTS 语音 | Edge TTS 在线语音（傲娇少女声线），Windows SAPI 兜底 |
| 情绪标签驱动 | LLM 回复自动解析【情绪】【动作】【特效】标签驱动动画 |
| 特效粒子 | 心形/星光/音符/月亮符文/月蚀黑雾 五种特效 |
| 语气词 | 摸头"哼~"/戳脸"呀！"/拖拽"喂喂！"/喂食"吧唧吧唧"/晚安"不准松开我" |

### 表情包映射

| 情绪 | 表情包 | 帧数 | 动画 |
|------|--------|------|------|
| 平静 | raise（举手） | 1 | 呼吸微动 |
| 开心 | play（玩耍） | 17 | 循环动画 |
| 生气 | kick（踢） | 35 | 循环动画 |
| 难过 | peeking（偷看） | 33 | 循环动画 |
| 惊讶 | peeking（偷看） | 33 | 快速循环 |
| 傲娇 | holdsign（举牌） | 2 | 交替帧 |

## 操作方式

| 操作 | 效果 |
|------|------|
| 左键单击 | 打开对话框，跟尤诺聊天（LLM 回复） |
| 左键双击 | 摸头 → "哼~" |
| 左键拖动 | 移动桌宠位置 → "喂喂！" |
| 滚轮 | 调整桌宠大小（80~500px） |
| 右键 | 打开菜单 |

## 右键菜单

- **跟我说话…** — 打开 LLM 对话输入框
- **喂食** — 播放"吧唧吧唧"
- **晚安** — 播放"不准松开我"
- **随机语气词** — 随机播放一条
- **调整大小** — 小/中/大/超大 四档
- **始终置顶** — 开关窗口置顶
- **跟随鼠标** — 开关桌宠自动跟随鼠标
- **语音开关** — 开关 TTS 语音播报
- **API 设置…** — 配置 LLM API 和 TTS 引擎（4 步向导）
- **退出程序**

## API 设置

首次使用需配置 LLM API（右键菜单 → API 设置）：

1. **API Base URL** — OpenAI 兼容接口地址，默认 `https://api.deepseek.com/v1`
   - DeepSeek: `https://api.deepseek.com/v1`
   - 通义千问: `https://dashscope.aliyuncs.com/compatible-mode/v1`
   - 豆包: `https://ark.cn-beijing.volces.com/api/v3`
   - OpenAI: `https://api.openai.com/v1`
2. **API Key** — 你的 API 密钥
3. **模型名称** — 默认 `deepseek-chat`
4. **TTS 引擎** — Edge TTS（在线，推荐）或 Windows SAPI（本地）

配置保存在 EXE 同目录的 `yuno_v4_config.json`，对话历史也会保存。

## 语音规则

- 默认所有 LLM 回复均转语音播报
- 长文本（>80字或含代码/数据/链接）自动跳过语音，只显示文字气泡
- 语气词优先级最高（摸头/戳脸等交互直接播放预录语音）
- Edge TTS 音色：`zh-CN-XiaoxiaoNeural`（晓萱，年轻少女声线），语速 +10%

## 稳定性

- 全 QThread 异步：LLM 请求和 TTS 生成均在后台线程，不阻塞 UI
- 全异常防护：每个 paintEvent/网络请求/文件操作都有 try-catch
- 资源正确释放：退出时停止所有定时器、线程、音效
- 无全局键盘钩子：避免 V2 的卡退问题
- 30fps 限帧动画：CPU 占用低

## 技术栈

- Python 3.12 + PyQt5（窗口/渲染/交互）
- requests（LLM API 调用）
- edge-tts（实时语音合成）
- PyInstaller（EXE 打包）
- 微信官方尤诺表情包（库洛游戏版权，个人使用）
