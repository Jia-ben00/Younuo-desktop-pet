# 鸣潮 · 尤诺团子 桌面宠物 v2 使用说明

在 v1 基础上加入 **人设 + 动态协议 + 语音模块** 的升级版。

## 运行

双击 `..\..\dist\尤诺桌宠v2.exe` 即可，无需安装环境。

> Windows 首次运行若提示"已保护你的电脑"，点"更多信息 → 仍要运行"（未签名，正常提示）。

## 操作方式

| 操作 | 效果 |
| --- | --- |
| 单击 | 戳脸 → 「呀！」+ 惊讶跳起 |
| 双击 | 摸头 → 「哼~」+ 开心转圈 |
| 左键拖拽 | 移动位置 → 松开触发「喂喂！」+ 生气冒烟 |
| 任意键盘按键 | 随机语气词 + 对应情绪（0.8s 冷却） |
| 滚轮（在桌宠上） | 调整大小（80~900px） |
| 右键菜单 · 喂食 | 「吧唧吧唧」+ 开心 |
| 右键菜单 · 晚安 | 「不准松开我」+ 傲娇别过头 |
| 右键菜单 · 跟我说话… | 输入任意文本朗读（>80 字或含代码/数据自动跳过语音，只显气泡） |

## 菜单项

- **调整大小**：小 / 中 / 大 / 超大
- **喂食 / 晚安 / 跟我说话…**：语音互动
- **语音开关**：关闭后只做表情动画、不发声
- **始终置顶 / 跟随鼠标**：同 v1
- **退出程序**

## 语音模块说明

- 语气词库为 **AI TTS 风格参考**生成（非真人克隆、无版权风险），5 条已内嵌：
  摸头 / 戳脸 / 拖拽 / 喂食 / 晚安。
- 说话时**口型联动**：ParamMouthOpenY 跟随音频电平开合。
- 「跟我说话…」使用系统 TTS（SAPI）兜底，音质为系统默认声线；
  若要更贴近尤诺音色，可接入支持情感参数的本地 TTS（如 CosyVoice），
  把 `docs/character_config.yaml` 里的 `tts_voice_desc` 填入音色 prompt。

## 动态协议

情绪状态机（平静 / 开心 / 生气 / 难过 / 惊讶 / 傲娇）+ 特效（脸红/冒烟/月亮/
眼泪/比心/耳朵/尾巴），详见 `docs/动态协议.md`。

## 文件结构

```
├── assets/
│   ├── iuno_pet.png              # 透明底角色图

    ├── character_config.yaml     # Open-LLM-VTuber 适配配置
    └── 使用说明.md
```

## 重新打包

英文路径 + 独立 venv（同 v1，见 v1/docs/使用说明.md）：

```powershell
pyinstaller --onefile --windowed --name 尤诺桌宠v2 \
  --icon assets\iuno.ico \
  --add-data "assets\iuno_pet.png;assets" \
  --add-data "assets\voice;assets\voice" \
  src\iuno_pet_v2.py
# conda Python 追加：--add-binary "D:\ProgramData\anaconda3\Library\bin\ffi.dll;."
```
