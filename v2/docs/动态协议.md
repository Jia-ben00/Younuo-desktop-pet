# 动态协议 · 尤诺团子 v2

「情绪 × 动作 × 特效」状态机。参数命名对齐 Live2D Cubism 标准参数，便于日后把
程序化精灵替换为真实 Live2D 模型时直接复用本协议。

## 情绪 → 动作 → 特效

| 情绪 | 动作 | 表情 / 特效参数 |
| --- | --- | --- |
| 平静（默认） | 待机呼吸 | ParamBreath 0~1 循环；尾巴轻摆；月亮符文常亮微光 |
| 开心 | 转圈（ParamBodyAngleZ ±15° 循环） | 脸红 ParamBlush≈0.6；尾巴高频摆动；月亮符文变亮 |
| 生气 | 快速抖动（dx ±3px @12Hz） | 炸毛冒烟 ParamSmoke=1；整体微放大 1.03 |
| 难过 | 缩团（scale 0.86 + 下沉） | 耳朵下垂 ParamEarL/R=-0.8；眼泪；轻微摇晃 |
| 惊讶 | 跳起（ParamBodyAngleY 上移抛物线） | 嘴开 ParamMouthOpenY=1；落地压扁回弹 |
| 傲娇 | 别过头（ParamAngleY -20°，偷瞄回摆） | 歪嘴 ParamMouthForm≈0.4；脸红≈0.85；比心 |
| 说话 | 口型联动 | ParamMouthOpenY 跟随音频电平（50ms 包络） |

## 团子专属自定义参数（建模时新增）

| 参数 | 含义 | 取值 |
| --- | --- | --- |
| ParamTail | 尾巴摆动 | 0~1 |
| ParamEarL / ParamEarR | 耳朵抖动 / 下垂 | -1（垂）~1（竖） |
| ParamBlush | 脸红 | 0~1 |
| ParamSmoke | 生气冒烟 | 0/1 |
| ParamMoon | 月亮符文 | 0~1（亮度） |
| ParamHands | 捂脸 / 比心 | 0/1 |

## 实现说明（当前版本）

v2 用**程序化 2D 变换 + 矢量特效**近似实现上述 Live2D 参数：旋转/缩放/位移驱动
精灵，脸红/冒烟/月亮/眼泪/比心/耳朵/尾巴由绘制层叠加。源码中 `_state()` 集中计算
各参数值，是接入真 Live2D 模型时的唯一改动点。
