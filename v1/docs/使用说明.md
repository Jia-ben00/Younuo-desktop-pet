# 鸣潮・尤诺团子 桌面宠物

一个透明、无边框、始终置顶的 Windows 桌面宠物程序，角色为《鸣潮》尤诺（玩家常称 "尤洛"）的官方周年庆团子形象。

## 运行

直接双击 `dist\尤诺桌宠.exe` 即可运行，无需安装任何环境。

> 说明：Windows 首次运行若提示 "Windows 已保护你的电脑"，点击 "更多信息 → 仍要运行" 即可（程序未签名，属正常提示）。

## 操作方式



| 操作           | 效果                             |
| ------------ | ------------------------------ |
| 左键按住拖动       | 移动桌宠位置                         |
| 鼠标滚轮（在桌宠上滚动） | 调整桌宠大小（80\~900px）              |
| 任意键盘按键       | 桌宠触发跳跃动画（全局键盘钩子同步）             |
| 右键点击桌宠       | 弹出菜单：调整大小 / 始终置顶 / 跟随鼠标 / 退出程序 |

## 菜单说明



* **调整大小**：小 (120px) / 中 (180px) / 大 (240px) / 超大 (320px)，也可直接用滚轮精细缩放

* **始终置顶**：勾选 = 窗口置顶在所有窗口之上；取消勾选则恢复正常层级

* **跟随鼠标**：勾选 = 桌宠默认平滑跟随鼠标光标（光标移近桌宠时自动暂停，方便交互）；取消则固定不动

* **退出程序**：关闭桌宠

## 特色



* 透明背景（角色周围可点击穿透，不挡桌面操作）

* 不进任务栏、不抢输入焦点，打字时不会被打断

* 默认开机跟随鼠标移动，可在菜单中关闭
