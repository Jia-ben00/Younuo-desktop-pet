# 尤诺团子桌面宠物 V3 使用说明

## 版本特性

- **2.5D 立体渲染**：QPainter 径向渐变球体 + 脸部贴图透视变形 + 3D 旋转动画，立体感强且打包零崩溃
- **去头饰重绘**：重新生成的干净尤诺团子形象（蓝发月牙、紫蓝大眼、腮红嘟嘴，无多余装饰）
- **三视图素材**：前/侧/后三个视角角色设定图（assets/original/three_view.png）
- **六情绪状态机**：平静/开心/生气/难过/惊讶/傲娇，每种情绪有独立的 2.5D 形变动画
- **语音模块**：5 条 AI TTS 语气词（摸头/戳脸/拖拽/喂食/晚安），QSoundEffect 异步播放，口型联动
- **交互**：左键拖动、单击戳脸、双击摸头、滚轮缩放、右键菜单
- **二次元 UI**：紫白渐变圆角右键菜单，emoji 图标，语音气泡
- **高稳定性**：无全局键盘钩子、全异常防护、30fps 限帧、资源正确释放，EXE 连续运行无崩溃

## 运行方式

双击 `dist/尤诺桌宠v3.exe` 即可运行，无需安装 Python 或任何依赖。

## 操作说明

| 操作 | 效果 |
|------|------|
| 左键拖动 | 移动桌宠位置，触发"喂喂！" |
| 左键单击 | 戳脸，触发"呀！" + 惊讶表情 |
| 左键双击 | 摸头，触发"哼~" + 开心表情 |
| 鼠标滚轮 | 缩放桌宠大小（80~500px） |
| 右键 | 打开菜单 |

## 右键菜单

- **喂食**：触发"吧唧吧唧" + 开心表情
- **晚安**：触发"不准松开我" + 傲娇表情
- **跟我说话…**：输入文字，桌宠会用语音念出来并显示气泡
- **随机语气词**：随机播放一条语气词
- **调整大小**：小(120px)/中(180px)/大(260px)/超大(360px)
- **始终置顶**：开关窗口置顶（默认开）
- **跟随鼠标**：开关桌宠自动跟随鼠标（默认开）
- **语音开关**：开关语音播放（默认开）
- **自动旋转**：开关平静状态下的左右摆动动画（默认开）
- **退出程序**：关闭桌宠

## 情绪与动画

| 情绪 | 触发 | 2.5D 形变 |
|------|------|-----------|
| 平静 | 默认 | 呼吸缩放 + 左右摆动 ±22° |
| 开心 | 摸头/喂食 | 横向挤压弹跳 + 腮红 + 微笑 |
| 生气 | 拖拽 | 放大抖动 + 头顶冒烟 |
| 难过 | — | 缩小下沉 |
| 惊讶 | 戳脸 | 纵向拉伸跳起 + 嘴张开 |
| 傲娇 | 晚安 | 别过头 -18° + 浓腮红 |

## 语音触发规则

- 默认所有交互均触发对应语气词语音
- 说话时嘴部区域跟随音频电平做口型联动
- 长文本（>80字或含代码）自动跳过语音，只显示文字气泡
- 语音可通过右键菜单关闭

## 技术栈

- Python 3 + PyQt5（QWidget + QPainter 2.5D 渲染）
- QSoundEffect（异步语音播放）
- PyInstaller（onefile 打包为独立 EXE）
- 无 OpenGL 依赖，彻底解决 PyOpenGL + PyInstaller 冻结崩溃问题

## 打包命令

```bash
# 在 ASCII 路径构建工作区执行（避免中文路径导致 Qt 插件错误）
pyinstaller --onefile --windowed --name IunoPetV3 \
  --icon assets/iuno.ico \
  --add-data "assets/iuno_face.png;assets" \
  --add-data "assets/voice;assets/voice" \
  src/iuno_pet_v3.py
```
