# 动态协议 V3 · 3D 形变映射

V3 将 V2 的 2D 特效升级为 **3D 网格形变**，参数仍对齐 Live2D Cubism 命名，
便于日后替换为真 Live2D 或高模 3D 模型。

## 情绪 → 3D 形变 → 语音

| 情绪 | 3D 形变（scale/rotate/translate） | 动画 | 语音 |
| --- | --- | --- | --- |
| 平静 | scale=(1,1,1)，呼吸 ±1.5% | 左右摆动 ±25°（Y 轴） | — |
| 开心 | scale=(1.08, 0.88, 1.08) 挤压 | 弹跳（Y 轴正弦） | 哼~ / 吧唧吧唧 |

| 难过 | scale=(0.88, 0.88, 0.88) 缩小 | 下沉（Y 轴 -0.3） | — |

## 团子专属参数（对齐 Live2D）

| 参数 | V3 实现 | 取值 |
| --- | --- | --- |
| ParamBodyAngleY | glRotatef(rotY, 0,1,0) | -25°（傲娇）~ +25°（摆动） |
| ParamBodyAngleZ | 预留（转圈） | ±15° |
| ParamBreath | scale 呼吸系数 | 0.985~1.015 |
| ParamMouthOpenY | 嘴部顶点外推形变 | 0~1（跟随音频电平） |
| ParamBlush | 贴图内置脸红 | 0~1 |
| ParamSmoke | 预留（2D 覆盖层） | 0/1 |
| ParamTail | 预留 | 0~1 |
| ParamEarL/R | 预留 | -1~1 |
| ParamMoon | 贴图内置月牙 | 0/1 |
| ParamHands | 预留 | 0/1 |

## 3D 模型技术细节

- **网格**：UV 球体，36 纬 × 54 经 = 1998 顶点，3888 三角形
- **贴图**：1024×512 equirectangular，正面脸（u=0.5）+ 背面蓝发（u=0/1）
- **光照**：GL_LIGHT0 方向光（1,1,2），漫反射 + 环境光，GL_COLOR_MATERIAL
- **渲染**：QOpenGLWidget，30fps，双缓冲，4x MSAA
- **透明**：WA_TranslucentBackground + alpha 通道 framebuffer，glClear alpha=0
